О проекте MTsouND

Учебный веб-портал об андеграундной музыке, эстетике звучания и основах саунд-дизайна.

Зачем нужен этот сайт

MTsouND задуман как компактный медиа-архив для тех, кто ценит живую энергию, плотный звук и честный подход к созданию музыки без глянцевых шаблонов.

Внутри собраны подборки треков с плеером, краткий разбор базовой обработки звука и шпаргалка по ключевым эффектам.

Технический стек

  • HTML5 — семантическая разметка страниц, таблицы и формы
  • CSS3 — Flexbox, Grid, оформление тёмной темы и адаптив
  • VS Code + Live Server — среда разработки и локальный сервер
